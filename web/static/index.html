同時録画最大4番組 (地デジ2 + BS2)。ライブ視聴もチューナーを1つ使用します

画面構成

デスクトップでは上部のタブバー、モバイルではボトムバーから各画面に移動できます。

視聴

  • ライブ — チャンネルカードをタップしてリアルタイム視聴 (同時最大2ストリーム)。画質はナビバー右上またはメニューから変更できます。視聴中にコントロールバーの録画ボタンで即座に録画を開始できます。NX-Jikkyo の実況コメントをオーバーレイまたはサイドバーで表示可能です
  • 番組表 — 新聞式グリッドで番組を表示。タップで詳細を開き、録画予約や録画ルール作成ができます

録画

  • 録画済み — 録画ファイルをシリーズ別に一覧表示。頭文字フィルタやキーワード検索で絞り込み、ブラウザ内再生やダウンロードが可能です。録画時に保存された実況コメント (.nicojk) も再生中に表示できます
  • 録画一覧 — 録画スケジュールの一覧。予定・録画中・完了・失敗・スキップの状態でフィルタできます
  • 録画ルール — キーワード・ジャンル・チャンネルで自動録画の条件を設定。ルールを削除・無効化すると、紐付く未実行の録画予定も自動で取り消されます。「無効ルールを削除」ボタンで不要なルールの一括削除も可能です
  • 番組改編 — シーズン切り替え時の録画ルール入れ替えを支援。EPG の【新】マーカーで新番組を検出し、ジャンルフィルタで絞り込んでルールを作成できます。終了番組タブでは未来にマッチ番組がないルールを検出し、一括無効化できます

その他 (···メニュー内)

  • ストレージ — 録画先ディスクの使用状況とシリーズ別の容量内訳を表示
  • ログ — 録画の開始・完了・エラーなどの履歴。レベル (info/warn/error) でフィルタ可能
  • アーカイブ — 過去に取得した全番組データをキーワード・ジャンル・日付・チャンネルで横断検索。EPG データは削除されず永続的に蓄積されます

録画の流れ

  1. EPG取得 — cron で1時間ごとに自動実行 (録画中はチューナー競合を避けるため自動スキップ)。各チャンネルを30秒間受信し、番組表データをDBに蓄積します
  2. 録画予約 — 録画ルールでキーワード条件を設定するか、番組表から番組を直接追加します。番組改編から新番組のルールを作成することもできます
  3. スケジュール生成 — EPG取得後に自動実行。ルールに一致する番組が録画一覧に登録され、crontab が更新されます。同じ番組の重複予約は自動で防止されます
  4. 録画実行 — 番組開始の1秒前に cron から自動的に録画が開始されます。recpt1 でチューナーを制御し、実況コメントも並行で保存します
  5. 完了 — 録画完了後、録画済みに表示されます。Discord / LINE への通知も送信されます

予約方法

方法1: 録画ルールで自動録画

録画ルール →「+ 録画ルール」で条件を登録。
キーワード (部分一致)・ジャンル・チャンネルを指定すると、一致する番組が自動的に録画予定に追加されます。
ルール作成時にマッチする番組のプレビューを確認できます。すべての条件は AND で評価され、未指定の項目はワイルドカード扱いになります。

方法2: 番組表から直接予約

番組表で番組をタップ →「録画予約」で1番組だけ直接予約。
「録画ルールを作成」を押すと、その番組名をキーワードにしたルールを作成できます。

方法3: 番組改編から新番組を予約

番組改編の新番組タブで、EPG に【新】マーカーが付いた番組を確認。
ジャンルフィルタで「アニメ／特撮」「ドラマ」等に絞り込み、「ルール作成」で録画ルールを作成できます。
既にルールが登録済みの番組は「登録済み」と表示されます。

番組改編 (シーズン管理)

4月・7月・10月・1月のシーズン切り替え時に、録画ルールの入れ替えを効率化するページです。

新番組タブ

EPG データのタイトルに含まれる【新】マーカーで新番組を自動検出します。
ジャンルフィルタ (アニメ／特撮、ドラマ等) で絞り込み可能。
複数チャンネルで放送される番組は自動的にグループ化されます。

終了番組タブ

有効な録画ルールのうち、未来の EPG にマッチする番組が存在しないルールを「終了候補」として表示します。
個別に無効化するか、「すべて無効化」で一括無効化できます。
無効化されたルールは録画ルールの「無効ルールを削除」で一括削除できます。

録画ファイルの保存先

録画ファイルはシリーズごとにフォルダ分けして保存されます。

ルール経由の録画: ルール名がフォルダ名になります (例: ルール名「進撃の巨人」→ /mnt/data/進撃の巨人/)
手動予約の録画: 番組タイトルからエピソード番号やサブタイトルを除去したシリーズ名が使われます

ファイル名: 日付_チャンネル_番組タイトル.ts
実況コメント: NX-Jikkyo のコメントが .nicojk ファイルとして自動保存されます (チャンネルマッピング設定時)

画質設定

デスクトップではナビバー右側のセレクト、モバイルではメニュー内の「画質」から3段階で切り替えられます。
ライブ視聴中・録画再生中に変更すると、即座に画質が切り替わります。

  • 高画質 — 元の解像度でトランスコード。LAN 環境向け
  • 中画質 — 640p / 800kbps。回線が遅い環境向け
  • 低画質 — 480p / 400kbps。モバイル回線向け

通知

録画の完了・失敗時に自動で通知を送信します。以下のサービスに対応しています。

  • Discord — Webhook URL を設定ファイルの DISCORD_WEBHOOK に指定
  • LINE Notify — トークンを LINE_NOTIFY_TOKEN に指定

ストレージ使用量がしきい値 (デフォルト: 使用率90%以上 or 残り50GB以下) を超えた場合にも警告通知が送信されます。通知はしきい値を超えた初回のみ送信され、空き容量が回復するとリセットされます。

ダークモード

OS のダークモード設定に自動追従します。手動での切り替えは不要です。

設定ファイル

conf/autorec.conf — メイン設定

RECORD_DIR録画保存先ディレクトリ
START_OFFSET番組開始の何秒前に録画開始するか (デフォルト: 1)
END_OFFSET番組終了の何秒後に録画停止するか (負値で早く停止、デフォルト: -1)
DISCORD_WEBHOOKDiscord 通知用 Webhook URL
LINE_NOTIFY_TOKENLINE Notify トークン
STORAGE_WARN_PERCENTストレージ警告しきい値 (使用率%、デフォルト: 90)
STORAGE_WARN_FREE_GBストレージ警告しきい値 (残りGB、デフォルト: 50)

conf/channels.conf — チャンネル定義

チャンネル番号 表示名 の形式で、recpt1 のチャンネル番号と表示名を定義します。
EPG 取得・録画・ライブ視聴で使用されます。

conf/jikkyo-map.conf — 実況コメント チャンネルマッピング

jk_ID チャンネル名 の形式で、NX-Jikkyo の実況チャンネルIDとチャンネル名を対応付けます。
設定されたチャンネルの録画時に実況コメントが自動保存されます。
